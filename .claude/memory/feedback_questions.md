Present every decision or clarification to the owner as a real question (the AskUserQuestion tool, up to 4 per batch), not buried in a prose report. For each option: a short label, a plain-English description of what it means, the **recommended option first** (label ends "(Recommended)"), and **why** it's recommended. Answers may add requirements ("…but global admin configurable"), so read them carefully and record them.

**Why:** Owner request 2026-09-25: "please present any clarifications or decisions as proper questions, including descriptions, your recommendations and why, so I can answer."

**How to apply:** Gather all open decisions first (HANDOFF §0 "❓ Owner decisions", task rows marked "waiting for owner", `LAUNCH_DECISIONS.md`), ask them up front in batches (most urgent first), then record every answer immediately in `.claude/HANDOFF.md` §0 and `LAUNCH_DECISIONS.md`, and carry on with the queue. Owner-only jobs that need no decision (billing, settings, secrets) go in a separate checklist, not as questions.
