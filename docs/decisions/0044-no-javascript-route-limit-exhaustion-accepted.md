# 0044 — The risk that a hostile script uses up the no-JavaScript route's limits is accepted

- **Date:** 2026-11-28
- **Question (plain words):** The route for visitors without JavaScript has strict limits. Someone hostile can use them up: stop one person using that route for a day, or fill a form's hourly allowance. The normal forms keep working. How should this be handled?
- **Answer (owner):** **Accept it.** Keep the strict limits and write the risk down. The limits stay adjustable in the admin screens.
- **Rules out:** raising the limits or redesigning the route before launch for this reason. It does **not** accept any way of getting round a limit.
- **Implemented in:** documentation (being written).
- **Supersedes:** nothing.
- **Issue:** #163.
