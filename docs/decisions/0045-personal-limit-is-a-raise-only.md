# 0045 — A person's own limit is a raise only

- **Date:** 2026-11-28
- **Question (plain words):** A Global Admin can approve more dynamic codes for one person. Should that number replace the plan's number, or only raise it? Should it apply while a payment is overdue?
- **Answer (owner):** **A raise only.** The person gets whichever is higher, their own number or their plan's. It is ignored while a payment is overdue.
- **Rules out:** a personal number lowering anyone's allowance; a personal number applying while a payment is overdue.
- **Implemented in:** not yet built (changes `c7687d3`).
- **Supersedes:** nothing (explains 0031).
- **Issue:** #164.
